Robust Foot-Mounted Inertial Sensor-Based Gait Analysis for Spatial-temporal Gait Parameters and Trajectory Estimation in Real-World Ambulatory Monitoring

Y. Liu, J. Ngan, A. A. S. Bhagat*

In preparation, target venue TBD

We present an insole-embedded, 9-axis IMU system that reconstructs foot trajectories and spatiotemporal gait parameters using VQF orientation estimation and a ZUPT-aided RTS error-state Kalman filter. Real-world track walking is benchmarked against Movella MVN Awinda using Bland–Altman and correlation analyses, showing that a simple insole system can approach the accuracy of a gold-standard motion capture setup in the field.
